# create-tiny-desktop

Scaffold a Tiny Desktop app for Windows, Linux, or macOS.

```bash
npx create-tiny-desktop my-app
cd my-app
npm run dev
npm run build
```

Use `--no-install` when you want to run installation separately:

```bash
npx create-tiny-desktop my-app --no-install
cd my-app
npm install
```

The generated project uses Vite and `tiny-desktop`. Only Node.js and npm are required.

Documentation: [Tiny Desktop](https://github.com/bgocumlu/tiny-desktop#readme).
